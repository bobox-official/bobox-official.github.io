Privacy Policy

Effective date: 29 September 2026

Bobox Publisher is a private command-line tool used only by the owner of the YouTube channel Bobox to manage that channel. This policy explains what data it uses and how.

YouTube API Services

Bobox Publisher uses YouTube API Services. By using it, you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy (also at www.google.com/policies/privacy).

What data is accessed

The only user is the channel owner. He signs in with his Google account through Google's OAuth 2.0 consent screen. The tool asks for these permissions:

  • youtube and youtube.readonly: to upload his own videos, edit their details (title, description, tags, translations, audience, publication date), set thumbnails and manage his channel's playlists and description;
  • yt-analytics.readonly: to read his own channel's statistics (views, watch time, subscribers).

The tool only accesses the channel owner's own channel. It does not access other users' data, comments, or any other channel.

How data is used, stored and shared

  • Data is used only to publish and manage the Bobox channel's videos, as described above.
  • The OAuth access and refresh tokens are stored only on the owner's computer, in a private configuration folder that isn't shared or synced. They are never sent anywhere except to Google.
  • Channel statistics are displayed to the owner when he asks for them, and are not kept after that.
  • No data is sold, shared with third parties, used for advertising, or combined with other data.
  • There is no website account, no server and no database. The tool does not use cookies. This website doesn't use cookies or analytics either.

Revoking access and deleting data

Access can be revoked at any time from the Google security settings page: security.google.com/settings/security/permissions. Deleting the local token file removes all stored authorization data. The tool does not keep any other copy of YouTube data. On request, any remaining stored data is deleted within 7 days.

Contact

Questions about this policy can be sent through the Bobox channel page or as an issue on this site's GitHub repository.

Changes

Any change to this policy will be published on this page with a new effective date.
